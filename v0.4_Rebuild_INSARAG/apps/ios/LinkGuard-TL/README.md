# LinkGuard-TL

小隊長與分區指揮版。

## 適用對象

- 小隊長
- 分區負責人
- ASR 區域管理員

## 核心權限

- 建立 ABC 區與 D1/D2 子區。
- 分區交接。
- 任務派遣與快速命令。
- 隊員配置。
- 建立會報、發布狀態、回報 ICS 資訊。
- 地圖畫線、畫面、危險區設定、搜索進度。
- 重機具、醫療、人力支援需求。
- AI 建議、區域風險評估、人力不足分析。

TL 是最重要的現場版本，會報系統預設只開給 TL 操作。

## TL/TE 手機端整合

手機版 TL 與 TE 共用同一套小隊作業 workflow。`LinkGuard-TL` 啟動時會提供分隊長、副分隊長、搜救員三個身分選項，選擇結果只顯示在畫面上；任務接收、GPS、照片、SOS、狀態回報與離線 queue 先維持一致功能面。
