# Event Schema

事件是 v0.3 所有工作流的共同單位。

## Required fields

- id
- type
- source app
- source role
- source device
- created time
- received time
- location
- priority
- sync state
- related ids

## Event types

- command
- alert
- task
- status report
- SOS
- medical update
- map update
- resource update
- finance record
- AAR audit event
