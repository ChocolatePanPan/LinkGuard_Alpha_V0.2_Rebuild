# Medical Layouts

Medical layouts 為 EMT 獨立設計。

## UI priorities

- triage category
- patient deterioration
- evacuation priority
- CCP capacity
- hospital capacity
- handoff status

## EMT phase layout

- iPhone EMT：以傷患建立、START、生命徵象、後送、照片、語音、SOS 作為第一層操作。
- iPad EMT：以 phase board、傷患清單、醫院容量、後送排序與交接狀態作為主要視覺。
- Phase 10 醫療AI預警只能作為輔助提示，不能取代 EMT 的 START 或後送決策。
- Phase 12 手錶整合顯示為生命徵象來源，不應讓感測同步狀態遮蔽檢傷分類。

## Rule

EMT 畫面不應以搜救進度或 ICS 分區指揮為主視覺。
