# Purchase Request

Purchase request 用於災害期間臨時採購與補給。

## Track

- request id
- requester
- reason
- item
- quantity
- estimated cost
- approval state
- linked task or sector

## Rule

Finance 紀錄需可追到核准人與作業需求。
