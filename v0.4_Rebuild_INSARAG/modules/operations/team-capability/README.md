# Team Capability

能力板用於快速知道每隊能做什麼、還能不能派。

## Track

- team type
- member count
- equipment
- medical capability
- canine or technical capability
- fatigue state
- current assignment
- availability time

## Use

SCC 與 UCC 用此資料分配 worksite 與支援需求。
# Team Capability

隊伍能力板用於 SCC/TL 快速判斷可派遣能力。

## Capability fields

- team id
- members count
- rescue skill
- medical skill
- rope skill
- K9 support
- heavy equipment
- fatigue level
- availability

## Rule

能力資料可由 TL 更新，SCC/UCC 用於派遣與資源協調。
