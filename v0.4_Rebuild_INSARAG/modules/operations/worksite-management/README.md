# Worksite Management

Worksite 是 INSARAG 現場作業的基本單位。

## Track

- worksite id
- sector
- location
- ASR level
- assigned team
- hazards
- access route
- marking status
- current task state

## Rule

Worksite 變更要同步到 SCC、TL 與相關 TE。
# Worksite Management

Worksite 是 INSARAG 搜救作業的核心單位。

## Track

- worksite id
- sector
- address or coordinates
- ASR level
- assigned teams
- hazards
- victims found
- marking state
- progress state

## Rule

Worksite 更新需同步到 SCC/UCC，並進入 AAR timeline。
