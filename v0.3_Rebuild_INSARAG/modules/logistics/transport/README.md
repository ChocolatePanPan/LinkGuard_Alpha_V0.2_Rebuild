# Transport

Transport 管理車輛、救護車與移動資源。

## Track

- vehicle id
- type
- capacity
- current location
- availability
- assigned mission
- driver or operator
- fuel state
- maintenance state

## Medical link

救護車後送資料要能連到 EMT Evacuation，但不公開完整醫療細節。
