# Supply Cache

Supply cache 管理物資位置與數量。

## Track

- supply id
- category
- quantity
- unit
- location
- owner
- minimum threshold
- expiration if any
- linked request

## Rule

低於門檻要通知 Logistics，不一定要打擾全部指揮鏈。
