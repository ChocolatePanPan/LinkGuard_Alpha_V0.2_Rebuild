# Staging Area

Staging area 是隊伍與資源待命位置。

## Track

- location
- capacity
- teams present
- resources present
- safety state
- access route
- communications status

## Rule

SCC 需要看到 staging area 是否可支持下一波任務。
# Staging Area

Staging Area 是隊伍與物資進入現場前的集結點。

## Track

- staging id
- location
- capacity
- assigned teams
- available resources
- safety status
- check-in and check-out
