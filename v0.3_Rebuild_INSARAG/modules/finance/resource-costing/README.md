# Resource Costing

Resource costing 用於估算任務成本。

## Cost inputs

- vehicle hours
- fuel
- consumables
- equipment damage
- purchased supplies
- personnel hours
- lodging or staging cost

## Rule

成本紀錄需能連到 operational period 與 AAR。
# Resource Costing

Resource Costing 將資源使用與成本做基本連結。

## Costable items

- personnel hours
- vehicle hours
- fuel
- equipment use
- consumables
- contracted service
- medical transport
