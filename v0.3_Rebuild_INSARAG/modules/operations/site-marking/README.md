# Site Marking

Site marking 用於現場標記與 RCM/INSARAG 狀態同步。

## Marking data

- marking type
- location
- worksite id
- team id
- time
- hazard note
- victim status
- access note
- photo reference

## Rule

標記更新必須出現在 tactical map 與 AAR timeline。
