# Situation Report

SITREP 用於 Planning 與指揮層共同理解態勢。

## Include

- current objective
- sector status
- worksite status
- hazards
- resources
- medical summary
- unresolved alerts
- next needs

## Rule

SITREP 應能從任務、地圖、醫療與資源狀態自動彙整。
