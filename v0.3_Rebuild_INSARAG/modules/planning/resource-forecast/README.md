# Resource Forecast

Resource forecast 預估下一階段需要的人力、裝備與醫療資源。

## Inputs

- active worksites
- hazard level
- trapped victim count
- team fatigue
- medical load
- weather or access constraints
- logistics status

## Output

提供 UCC/SCC 調度與 Finance 預估成本使用。
