# Incident Action Plan

IAP 是指揮目標、資源、風險與作業期的整理。

## Sections

- incident objectives
- organization assignment
- communications plan
- medical plan
- safety message
- resource assignment
- map attachment
- next operational period

## Rule

IAP 應從既有資料組成，不應讓使用者重打所有內容。
