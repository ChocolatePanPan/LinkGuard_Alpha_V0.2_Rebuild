# Alert Center

Alert Center 管理重大警報、確認與逾時追蹤。

## Alert classes

- evacuation
- collapse risk
- fire or smoke
- hazardous material
- medical surge
- missing team
- communications failure

## Required behavior

每個警報必須追蹤已讀、確認、逾時與強制確認原因。
# Alert Center

Alert Center 管理重大警報與確認狀態。

## Alert types

- evacuation
- collapse risk
- weather
- hazardous material
- missing member
- medical mass casualty
- communication outage

## Rule

警報必須可追蹤 read、acknowledged、overdue 與 forced confirmation。
