# Incident Command

Incident Command 是 UCC/SCC 的最高命令入口。

## Responsibilities

- establish incident objectives
- assign ICS positions
- approve major alerts
- set operational period
- approve evacuation or stand-down
- trigger AAR closeout

## Records

每個重大決策都必須連到 decision log 與 command trace。
# Incident Command

Incident Command 是 UCC/SCC 的最高指揮入口。

## Responsibilities

- establish incident objectives
- assign ICS positions
- approve major alerts
- approve sector structure
- review operational period changes
- close incident and trigger AAR

## Rule

每個重大決策都要產生 decision log 與 command trace。
