# Briefing

Briefing 用於指揮層與小隊長，VO/TE 只接收與自身任務相關摘要。

## Briefing content

- incident objective
- current hazards
- sector assignments
- worksite priorities
- medical status summary
- communications plan
- next operational period

## TL-only mode

小隊長可取得完整任務會報，但隊員只接收必要任務與安全資訊。
# Briefing

Briefing 是 TL 與 SCC 的任務交接核心。

## Briefing content

- objective
- current hazards
- assigned worksite
- map references
- team composition
- radio or network channel
- safety notes
- medical route

## Rule

TL 可接收完整小隊 briefing，TE/VO 只接收與自己任務相關的摘要。
