# ICS and INSARAG Mapping

LinkGuard v0.3 同時採用 ICS 管理骨架與 INSARAG 搜救流程。

## ICS provides

- Command
- Operations
- Planning
- Logistics
- Finance
- 職位與權限
- 指令流向

## INSARAG provides

- UCC/SCC/Worksite/Squad 作業脈絡
- ASR 分級
- RCM 標記
- 搜救會報與任務回報
- 醫療後送與現場協調

## Design rule

ICS 是管理結構，INSARAG 是搜救方法。兩者在資料層需合併，不應做成兩套互相競爭的頁面。
