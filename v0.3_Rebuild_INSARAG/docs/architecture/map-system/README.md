# LinkGuard-E 地圖系統功能架構

地圖系統是整個 LinkGuard-E 的核心，不是附屬元件。

訪談摘要重點：

- 地圖要能直接看懂現場
- 不能點很多層
- 高壓下要快速判讀
- 資訊要分層
- 介面要像作戰地圖

因此地圖定位為「災害指揮作戰平台」，不只顯示位置。

| 搜救狀態 | 搜救中/淨空 | 搜索進度 |

| AI分析圖層 | AI風險區 | 決策輔助 |

## 點線面功能

### 點（Point）

代表單一位置。

| 類型 | 說明 |
| --- | --- |
| SOS | 緊急求救 |
| 傷患 | 傷患位置 |
| 受困者 | 生還者定位 |
| 隊員 | 搜救員位置 |
| 危險點 | 瓦斯/電線 |
| 臨時據點 | 集結點 |
| 醫療站 | EMT位置 |
| 指揮所 | SCC/UCC |

顏色建議：

| 顏色 | 代表 |
| --- | --- |
| 紅色 | SOS/危險 |
| 黃色 | 傷患 |
| 綠色 | 已安全 |
| 藍色 | 隊伍 |
| 黑色 | 禁止進入 |

### 線（Line）

代表路線、邊界、動線。

| 類型 | 說明 |
| --- | --- |
| 撤離路線 | 緊急撤退 |
| 危險路線 | 禁止通行 |
| 搜索動線 | 搜救路徑 |
| 補給路線 | 物資運送 |
| 封鎖線 | 安全管制 |
| 通道 | 可通行區域 |

### 面（Polygon）

代表區域範圍。

| 類型 | 說明 |
| --- | --- |
| 倒塌區 | 主災區 |
| 搜救區 | ABC分區 |
| 子區域 | D1/D2 |
| 危險區 | 禁止進入 |
| 已淨空區 | 已完成搜索 |
| 火災區 | 高危險區 |
| 化學危害區 | 毒性區域 |

## 主頁排序與資訊架構

地圖頁面排序（依訪談）：

1. 地圖
2. 人員總覽
3. 資源管理
4. 通訊

地圖必須是：

- 開啟APP第一頁
- 最大頁面
- 指揮核心
- 全系統主入口
