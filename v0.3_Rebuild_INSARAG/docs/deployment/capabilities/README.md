# Capabilities

各 app 能力需依角色開啟，不應全部開到最大。

## Common capabilities

- local network
- camera
- photo library add only
- microphone
- location when in use
- background processing for sync

## Role-specific

- EMT：health-adjacent data handling policy, camera, microphone, location.
- TL/SCC/UCC：local network, map, push or local alert.
- VO/TE：minimal capability set plus SOS.
