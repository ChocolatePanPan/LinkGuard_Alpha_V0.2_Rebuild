- `implementation-status/README.md`：v0.3 目前完成度、產品化缺口與下一步順序。
- `architecture/`：App family、資料流、Xcode project 與角色功能矩陣。

- `permissions/`：app 權限、醫療資料邊界與指揮權限。
- `workflows/`：事件、地圖、SOS、醫療、離線同步與 AAR 流程。
- `testing/`：field drill、validation plan 與 offline chaos 驗證。
