# Accessibility

救災 UI 需要在壓力、手套、戶外光線與噪音環境下可用。

## Requirements

- large tap targets
- high contrast status colors
- voice output for critical alerts
- readable offline state
- visible confirmation states
- no hidden critical action behind gestures only

## Priority

SOS、警報確認、醫療紅色傷患、撤離命令必須優先符合可讀與可操作標準。
